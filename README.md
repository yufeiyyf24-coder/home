# 小家 · 原型

小家的可点击原型。底子是用 Codex 重做的那一版（纸张、宋体、手账感），在这个基础上继续改。

完整交互规则见 [INTERACTION.md](INTERACTION.md)。

视觉数值按 `代码参考.txt`（Figma 导出的 首页 / 左抽屉 / 设置 / 选择模型 / 收藏）对齐：底色 `#FFFDEF`、主色 `#736249`、强调 `#E9A866`、卡片 `rgba(255,255,255,.51)`。日记展示页按 `1.txt` 对齐：幼圆标题、卡外作者名、白色渐隐卡片、330×486 阅读纸卡。

## 打开

- 双击 `preview.html`：412 × 917 的手机壳预览，带状态栏和手势条。
- 双击 `index.html`：直接看界面，铺满浏览器窗口。

纯静态，无依赖，不需要起服务。数据和设置存在浏览器的 localStorage 里；设置 → 数据 → 重置演示数据可以清空重来。

## 现在能点的

**聊天**
- 7 段按时段切换的空态问候
- 发消息 → 正在思考 → 思考流（开启思考时）→ 逐字流式正文
- 发送键常驻：空内容灰色不可点，有字变橙；生成中输入为空时变成停止键
- 生成中再发会排队，当前回复结束后逐条发；停止只停当前一条
- 输入框右下角显示上下文占用百分比（≥70% 橙、≥90% 深棕）
- 消息工具：复制、编辑（保存后重发）、重新生成（直接替换）、收藏、收入日记、删除
- 删除用户消息会连带删掉它后面那条 AI 回复
- 长按 / 右键消息出菜单；「多选」进入选择模式，双方消息都能选，可批量删除
- 多选底部是删除和导出两个图标；点导出后选「图片 / 文档」，两者目前都是原型占位说明，真实导出等 M1
- 顶栏：左侧会话历史；右侧电脑图标（仅在线时显示）+ 新对话

**会话历史**
- 搜索会话名和正文；7 天内 / 30 天内 / 年月分组
- 当前会话高亮，时间位置换成 `•••`：重命名 / 置顶 / 删除（删除后 5 秒内可撤销）
- 点其他会话只切换背后的聊天，不关抽屉；从抽屉进入的页面，返回后抽屉会重新打开
- 多选：点「会话历史」右侧的多选图标进入选择模式，勾选会话后在底部批量置顶 / 删除（删除可撤销）

**我们的**
- 日记时间轴：小D 和清霖各写各的；日期尺拖动选日期
- 日历：两色点标注谁写了，选日期后「查看」跳到当天日记
- 点开是一张浮起的阅读纸卡：高度随内容变化，最高 486px，正文再长就在卡片内上下滑动；左上角作者标签、12px 正文、底部编辑/收藏/删除图标，点背景或右上角关闭（按 1.txt 的日记展示页）
- 日记可写、可编辑、可删除、可收藏；记忆和收藏沿用
- 收藏按 Figma 做成左侧色条卡片（日记 / 对话两种颜色），带虚线边框和时间戳；预置了 4 条收藏，都是小D想留下来的小事
- 对话收藏点开后可以「回到原对话」，跳到那条消息并高亮一下；原对话不在了会提示

**小本本**
- 小D的备忘录，按 今日 / 本周 / 长期 分组，可勾选完成、点文字编辑、加号添加、× 删除
- 规划含今日三餐、本月运动日历，右上「本周计划」可打开浮层（内容是示例数据）

**设置**
- 通用：主题色三套、字体、字号（真实生效）
- 配置：模型浮层、电脑连接页（在线/离线、断开与重连、历史操作）、工具管理、插件、权限
- 数据：备份导出、清理缓存、日志、重置演示数据
